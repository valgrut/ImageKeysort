Available shortcuts

  • [a-zA-Z]+ – Add shortcut (Edit mode) / Use shortcut (Sort mode)
  • [a-zA-Z]?-[a-zA-Z] - Remove key after '-' from key before '-'
  • Ctrl+C – Toggle copy mode
  • Ctrl+E – Set Edit mode
  • Ctrl+R – Set Sort mode
  • . – Repeat last source -> destination transition
  • Space – One-time move/copy of current item even without a full shortcut sequence
  • Left/Right arrow – Go to next/previous image in selected directory.
  • Ctrl+Z – Undo last operation (swap src/dst and re-execute)
  • Ctrl+L – Load predefined shortcuts
  • Ctrl+O – Open and load directory as source
  • Delete – Delete current image/video
  • Esc – Clear current shortcut sequence
  • Enter – Insert sentinel (“+”) at current position in the shortcut sequence.
    Example: ab<Enter> -> ab+, then cd -> ab+cd.
    Pressing Esc removes only the part after the sentinel, keeping ab+ instead of clearing the whole sequence.
  • Ctrl+, – Open settings

Example use-case:

  • 1. Ctrl + E - set edit mode
  • 2. ic ENTER - add shortcut 'i+c' (Images/Cats) and select target directory for it.
  • 3. Ctrl + R - set Sort mode
  • 4. Ctrl + O - Select directory, which you want to sort.
  • 5. ic - Current image will be moved into directory selected for 'ic' shortcut.
