Image Keysort

Author: Jiri Peska

Image Keysort is a keyboard-driven tool for quick images and videos sorting and organization. It lets user to define character sequences that are mapped to directories, and just by typing this sequence, app will move current image to the directory corresponding to that sequence. Fly through large folders and sort it using only the keyboard.

GitHub: github.com/valgrut/image-keysort
